# 百合会文学区 · Legado 书源

这是面向 Legado（阅读）的百合会论坛小说书源，只包含：

- 文学区：`https://bbs.yamibo.com/forum-49-1.html`
- 轻小说/译文区：`https://bbs.yamibo.com/forum-55-1.html`
- 当前百合会账号的帖子收藏

## 导入

在 Legado 中打开“书源管理 → 本地导入”，选择：

`dist/yamibo-legado-book-source.json`

请导入 `dist` 内的 JSON。当前成品使用传统书源规则格式，兼容尚未支持 `mainJs` 单文件接口的 Legado 正式版。

也可以在 Legado 中使用网络导入地址：

`https://raw.githubusercontent.com/chris7395328/yamibo-legado-book-source/main/dist/yamibo-legado-book-source.json`

以后更新仓库后，在 Legado 的书源管理中使用该地址重新导入即可。

## 登录和阅读

1. 在书源管理中打开该书源的“登录”，用 Legado 内置网页完成百合会登录。筛选书源的三个发现入口仅用于浏览，不能放置独立登录按钮；未登录时，阅读页的“书源功能”按钮也会直接打开登录页。
2. 从“发现”进入“文学区”“轻小说/译文区”或“我的帖子收藏”。本书源没有搜索功能，也不会扫描论坛搜索结果。
3. 选择帖子后加入书架或直接阅读。

一个帖子会成为一本书。“只看楼主”页面里的每一条楼主发帖会按顺序成为一节，普通读者回复不会进入正文。

帖子列表不会额外访问详情页；进入帖子详情后才会尝试把首帖第一张有效图片设为封面。简介取首帖纯文本的前 200 字。

百合会正文里的 `<ruby>/<rt>` 注音或行间备注会转换为 `正文〔注音〕`。Legado 的网页书源净化流程不可靠保留 ruby 上方注音排版，这样可避免注音直接粘在正文后面。

阅读页底部会显示书源自定义按钮：

- 点击：登录后把当前帖子收藏到百合会账号；未登录时打开百合会登录页。
- 长按：在 Legado 内置网页中打开原帖。

需要论坛阅读权限的帖子仍以登录账号的实际权限为准。遇到登录失效时，重新打开书源登录页即可刷新 Cookie。

## 开发

- `src/yamibo.js`：新版单文件接口的参考实现（成品暂不依赖它）。
- `src/callback.js`：收藏按钮及长按打开原帖。
- `build.ps1`：生成传统规则格式的可导入 JSON。

修改源码后，在本目录运行 `./build.ps1` 重新打包。

## 长帖目录

打开帖子或刷新目录时，书源会先取得论坛实际的“只看该作者”链接，再由 Legado 顺序读取该链接的分页生成目录；不会先扫描未筛选的普通回复页，普通读者回复也不会进入目录。长帖请求已限制为单请求节流。

书架的“允许更新”只表示 Legado 可以在书架刷新或阅读进度接近末尾时检查目录，并不代表每次启动应用都会自动刷新。连载帖可开启，完结帖可关闭；需要获取新增楼层时再手动刷新目录。

## 已知边界

- 收藏入口展示账号的全部“帖子收藏”，其中可能包含文学区以外的旧收藏；打开后仍按论坛帖子方式读取。
- 章节名从楼主楼层中的短标题或正文开头自动生成，因此部分帖子的章节名会是正文摘要。
